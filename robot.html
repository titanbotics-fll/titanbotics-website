Robot notebook · BIOGLOW 2026–27

This week: attachments!

We’re learning new things every week—one step at a time. This week, we explored how to control our robot’s right arm.

Find a start.
Move. Pause. Return.

  1. Find the starting point. Run the arm until it stalls, with the motor duty limited to 25%. For this setup, the idea is to find the arm’s mechanical stop.
  2. Call that position zero. Reset the angle reading to 0°. This labels the position; it doesn’t move the arm.
  3. Try different positions. Tell the arm to go to 180°, then 90°, then 120°, pausing for two seconds at each.
  4. Come back to zero. Return to the starting angle and hold it.

Our angle plan: 0° → 180° → 90° → 120° → 0°

Each target is measured from zero. Going to 90° after 180° means moving back toward zero, not adding another 90°.

Peek at our Python code

Our lesson snippet. It uses Motor, Port, Stop, and wait from our robot program.

right_arm = Motor(Port.F, gears=[[28, 36], [12, 20]])

right_arm.run_until_stalled(-300, then=Stop.HOLD, duty_limit=25)
right_arm.reset_angle(0)
right_arm.run_target(100, 180, then=Stop.HOLD)
wait(2000)
right_arm.run_target(100, 90, then=Stop.HOLD)
wait(2000)
right_arm.run_target(100, 120, then=Stop.HOLD)
wait(2000)
right_arm.run_target(100, 0, then=Stop.HOLD)

Port F connects the motor. The gear lists describe our two gear stages, so Pybricks accounts for the gearing. Stop.HOLD keeps the arm at its target.

From our robot notebook

Will it come back to the same spot?

We’ve been exploring a curved path: drive out, then reverse along the same curve. The question is simple. Does the robot end up where it started?

  1. Make a prediction. Mark the starting point and guess where the robot will finish.
  2. Try it. Run the movement and compare the finishing position with the mark.
  3. Try one change. Change the speed, repeat the test, and see if the result is different.

A question we’re working on—not a finished result. Our measurements and discoveries belong here next.

Will it come back to the same spot?

We’ve been exploring a curved path: drive out, then reverse along the same curve. The question is simple. Does the robot end up where it started?

  1. Make a prediction. Mark the starting point and guess where the robot will finish.
  2. Try it. Run the movement and compare the finishing position with the mark.
  3. Try one change. Change the speed, repeat the test, and see if the result is different.
